# 🐄 FermaApp — AND BILLUR Ferma boshqaruv tizimi

## Ishga tushirish

```bash
node server.js
```

Brauzerda oching: **http://localhost:3000**

## Default login
- Username: `admin`
- Parol: `admin123`

## Modullar

| Modul       | Tavsif                                      |
|-------------|---------------------------------------------|
| Dashboard   | Kunlik sut, 7 kunlik grafik, statistika     |
| Mollar      | 600+ mol, quloq raqami, holat, tahrirlash   |
| Sut         | Kunlik soqim (1-2 marta), Nestle hisobi     |
| Moliya      | Kun/hafta/oy/yil daromad va harajat (admin) |
| Harajatlar  | Em-xashak, dori, mehnat va boshqa           |
| Admin       | Foydalanuvchilar boshqaruvi                 |

## Mol holatlari
- **Sut beradi** — faol soqim
- **Vaqtincha yo'q** — to'xtatilgan
- **Kasal** — davolanmoqda
- **Bozak** — yosh buzoq/nam
- **Sotildi** — chiqarilgan

## Fayl tuzilishi
```
ferma-app/
├── server.js        # Backend (Node.js built-in modules only)
├── db.json          # Ma'lumotlar bazasi (auto yaratiladi)
├── package.json
└── public/
    └── index.html   # Frontend SPA
```

## Android/Termux
```bash
node server.js
# Telefondan: http://localhost:3000
# Boshqa qurilmadan: http://<IP>:3000
```
